# Open Flow

Free voice dictation for Mac and Windows. Hold a key, speak, and clean text appears in any app.

**Website:** https://rag-kr.github.io/OpenFlow-releases/

## Download (latest)
- [Mac, Apple Silicon (M1 and newer)](https://github.com/RAG-KR/OpenFlow-releases/releases/latest/download/Open-Flow-mac-apple-silicon.dmg)
- [Mac, Intel](https://github.com/RAG-KR/OpenFlow-releases/releases/latest/download/Open-Flow-mac-intel.dmg)
- [Windows](https://github.com/RAG-KR/OpenFlow-releases/releases/latest/download/Open-Flow-windows-setup.exe)

## Install
**Mac:** open the DMG, drag Open Flow to Applications, open it. If macOS blocks it: System Settings → Privacy & Security → **Open Anyway** (once). Allow Microphone and Accessibility.

**Windows:** run the installer. If you see "Windows protected your PC": **More info → Run anyway** (once). Allow the microphone.

**Then:** get a free key at [console.groq.com/keys](https://console.groq.com/keys) and paste it on the **AI cleanup** page.

## Use
Hold **⌥ Space** (Mac) / **Ctrl Space** (Windows), speak, let go. The bar at the bottom of your screen walks you through the rest.

This repository only hosts installers; the source is not public. Report problems in Issues.
